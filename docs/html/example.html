What the standard is (with example)

You agreed to all Hermes recommendations. This page states the resulting contract and walks a concrete commodity commit / forecast package shaped like BBU/PSU planning.

1. The standard in one paragraph

Every planning agent that pair-works with a human planner must complete each cycle as an Analysis Package: pinned inputs, versioned method, deterministic engines for math, human deltas as labeled overrides/judgments/truths, declared outputs, and a machine QA gate. Portable directory (RO-Crate profile under the hood; YAML convenience manifest for humans/agents). Extensible via pack-type profiles - not one global BOM religion.

3. Runtime flow (agent + human)

1. Open/create package for the cycle
2. Pin inputs (snapshot_id + hash or external_ref escape hatch)
3. Run deterministic engines via method.entrypoint
4. Write human/accepted deltas to labels/*.jsonl (never silent cell paint)
5. Emit outputs listed in output_contract only
6. ap-gate check . must pass before approved / “final”
