# Backup product names - sounding-line family

**Date:** 2026-08-16  
**Purpose:** Coined (or lightly coined) alternatives if **fathm** fails clearance or market confusion.  
**Keep either way:** Analysis Package (`ap`) format name, chart-room metaphor, brass/ink system, F-as-instrument *only if* we keep a letter-mark story.

Not legal clearance. Spot-check domains/TESS before locking any of these.

---

## Selection criteria

1. Speakable once  
2. Not a crowded AI SaaS word (audit, trace, provenance alone are weak)  
3. Fits **measure what you can't see** / commit under uncertainty  
4. Works as verb or concrete noun  
5. Logo can stay nautical without depending on the word "fathom"

---

## Option A - **leadline**

| | |
|--|--|
| **Sense** | Weighted line cast to take a sounding; also "the sentence that leads." |
| **One-liner** | leadline - every analysis on a line you can pull. |
| **Definition device** | leadline *(n.)* - the line you trust when you cannot see the bottom. |
| **Pros** | Distinct from fathom.ai; still pure sounding vocabulary; good for CI "on the leadline" |
| **Cons** | Two syllables; may need "lead line" education; check LEADLINE marks |
| **Domain hunches** | leadline.ai / getleadline.com |
| **Tone** | Operator, slightly harder-edged than fathm |

**Pitch fit:** gate = make the package safe to hang on the leadline.

## Option B - **keelmark**

| | |
|--|--|
| **Sense** | Permanent reference mark on a vessel; what you measure draft against. |
| **One-liner** | keelmark - the permanent mark every analysis must clear. |
| **Definition device** | keelmark *(n.)* - a fixed reference. what the sounding is measured against. |
| **Pros** | Strong "standard + gate" story; unique coinage feel; logo = notch/mark |
| **Cons** | Less warm; "keel" is boat-nerdy; inventedness can help TM |
| **Domain hunches** | keelmark.ai / keelmark.io |
| **Tone** | Standard-first, compliance-friendly |

**Pitch fit:** the Standard is the keelmark; CI checks you didn't load past it.

## Option C - **plumb** (product) / **plumbpack** (if bare plumb is weak)

| | |
|--|--|
| **Sense** | Plumb line - true vertical; "plumb the depths"; honesty ("plumb wrong"). |
| **One-liner** | plumb - make every analysis true to its source. |
| **Definition device** | plumb *(v.)* - to test for true depth and alignment. |
| **Pros** | Short; verb brand energy; depth + truth double meaning |
| **Cons** | Common English + plumbing industry noise; may need **plumbpack** or **plumbgate** for search; TM descriptiveness risk |
| **Domain hunches** | getplumb.com / plumbpack.ai |
| **Tone** | Closest emotional cousin to fathm |

**Pitch fit:** if fathm is blocked mainly by fathom.ai noise, plumb keeps the depth story without the same autocomplete death.
